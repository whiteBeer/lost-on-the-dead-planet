# Скины Wave Arena

Сгенерированы 2026-11-21 встроенным image_gen по навыку imagegen. PNG с настоящим alpha, 1254×1254. Оригиналы сохранены без растрового редактирования; игра уменьшает их до игровых кадров при загрузке. Скин меняет только графику, не характеристики.

Файлы: `ember.png` («Алый рейдер»), `frost.png` («Север»), `viper.png` («Радиолог»), `spectre.png` («Призрак»). Каталог и цены авторитетны в `backend/configs/Shop.ts`.

Общий промпт (для каждого файла отдельный вызов built-in, transparent_background=true):

> Use case: stylized-concept. Asset type: actual transparent 2D player sprite for a top-down browser zombie survival shooter, not a store illustration. ONE compact chibi survivor, helmet and rounded shoulder armor, seen from steep top-down 70-degree view, head above torso and two hands holding a short generic rifle pointing toward the bottom edge of the image. Full character and entire gun visible, centred, occupying about 75% of square canvas, generous transparent padding. Hand drawn 2D cartoon game sprite, thick dark outlines, simple cel shading, crisp limited-colour shapes readable when reduced to 40 pixels, consistent proportions: big helmet, broad shoulders, tiny foreshortened legs. No floor, no shadows outside silhouette, no border, no text, no logos, no UI. Genuine transparent alpha background.
